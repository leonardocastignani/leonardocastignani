## 👨‍💻 Su di me

Sono uno **sviluppatore freelance** con base nelle Marche, attualmente al terzo anno di **Laurea Triennale in Informatica** presso l'Università degli Studi di Camerino.

Mi occupo di sviluppo web e software a 360°: dal sito vetrina all'applicazione web complessa, curando ogni fase del progetto con attenzione alla qualità del codice, alle performance e alla UX.

Quando non scrivo codice, mi trovi a parlare di **macchine e moto** 🏎️🏍️
